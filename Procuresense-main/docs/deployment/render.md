# Deployment Guide — Render

## Prerequisites
- GitHub repository connected to Render
- `render.yaml` at project root

## Steps

1. Push code to GitHub `main` branch
2. Go to [Render Dashboard](https://dashboard.render.com)
3. Click **New** → **Blueprint**
4. Connect your GitHub repo
5. Render auto-reads `render.yaml` and provisions:
   - `procuresense-frontend` (Static Site)
   - `procuresense-backend` (Web Service — Node.js)
   - `procuresense-ml` (Web Service — Python)
   - `procuresense-db` (PostgreSQL)

## Environment Variables

Set these manually in the Render dashboard (secrets not in render.yaml):
- `JWT_SECRET` — auto-generated by Render
- `JWT_REFRESH_SECRET` — auto-generated by Render
- `API_KEY` — auto-generated by Render

## Database Migrations

Migrations run automatically on backend deploy via:
```
npx prisma migrate deploy
```

## ML Model Deployment

Place trained `.pkl` / `.joblib` files in `ml-service/trained_models/`.
They are loaded at FastAPI startup via the model loader service.
